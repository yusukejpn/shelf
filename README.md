# Shelf ファイルビューア

Claudeで作ったHTMLやMarkdownのファイルを取り込んで、スマホでオフラインでもすぐ開けるWebアプリ（PWA）です。

- ほかのアプリの「共有」から直接取り込める（Androidでインストールした場合）
- HTMLはボタンやアニメーションも動く。ページ内のチェック状態なども保存される
- Markdownは読みやすく整形して表示（表・コード・チェックリスト対応）
- ファイルは端末の中だけに保存。サーバーには送らない

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体 |
| `db.js` | 端末内の保存（IndexedDB） |
| `sw.js` | オフライン対応と共有の受け取り |
| `manifest.webmanifest` | ホーム画面に入れるための設定 |
| `marked.js` | Markdown変換ライブラリ（marked v4.3.0、MITライセンス、`marked-LICENSE.md`） |
| `icons/` | アプリアイコン |

## 公開のしかた（GitHub Pages・無料）

PWAはHTTPSで公開する必要があります。いちばん簡単なのはGitHub Pagesです。

1. GitHubで新しいリポジトリを作る（例：`shelf`）。**Public** を選ぶ。
2. リポジトリの画面で **Add file → Upload files** を開き、このフォルダの中身（`index.html` など全部と `icons` フォルダ）をドラッグ＆ドロップして **Commit changes**。
3. **Settings → Pages** を開き、Source を **Deploy from a branch**、Branch を **main / (root)** にして **Save**。
4. 1〜2分待つと `https://<ユーザー名>.github.io/shelf/` で開けるようになる。

git を使う場合は、このフォルダで `git init` → コミット → push でも同じです。

> 公開されるのはアプリの「入れ物」だけです。取り込んだファイルは各端末の中にしか保存されないので、URLを知られても中身は見えません。

## Pixel（Android）に入れる

1. Chromeで上のURLを開く。
2. メニュー（⋮）→ **アプリをインストール**（または「ホーム画面に追加」）。
3. ホーム画面の **Shelf** から起動。一度開けば以降はオフラインでも動きます。

## 取り込み方

- **共有から**：ファイルアプリ・Googleドライブ・Claudeアプリなどでファイルを「共有」→ **Shelf**。
  ※共有メニューに出るのは、アプリとしてインストールした後です。
- **追加ボタンから**：右下の「追加」→ 端末のファイルを選ぶ（複数可）／テキストを貼り付け。
- 同じ名前のファイルを取り込むと上書き（ページの保存データは残る）。

## 更新するとき

アプリを直したら `sw.js` の `CACHE = 'shelf-v1'` の数字を上げてからアップロードすると、スマホ側に新しい版が確実に届きます。
